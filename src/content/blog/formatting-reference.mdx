This entry is a draft, so it only appears when running `npm run dev`. It exists to show how each Markdown and MDX element looks in the journal. Copy what you need, then delete what you don't. The first paragraph of an entry is set slightly larger, as an introduction.

Ordinary paragraphs follow. Text can be **strong**, *emphasized*, or contain `inline code` and keyboard shortcuts such as <kbd>Super</kbd> <kbd>Tab</kbd>. Links look [like this](https://github.com/vela-desktop/vela). Footnotes are supported too.[^1]

## A section heading

Second-level headings divide an entry into sections. Hover one to reveal its anchor link; the `#` copies a direct URL to that section.

### A smaller heading

Third-level headings work inside a section.

#### A label heading

Fourth-level headings are set as small labels.
